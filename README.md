# URA OSINT Monitoring Dashboard

Illegal accommodation listing detection tool for Carousell, Facebook Marketplace, and Xiaohongshu.

Built by Talons Laboratories.

## What this does

Scrapes rental listings from online platforms, flags suspected illegal short-term accommodation and unauthorised dormitory listings using keyword matching and risk scoring, and surfaces them in a dashboard for human review.

## Platforms covered

- Carousell (live)
- Facebook Marketplace (in progress)
- Xiaohongshu (planned)

## Features

- Keyword matching (English + Chinese + coded slang)
- Risk scoring (HIGH / MEDIUM / LOW)
- Filter by platform, risk level, district, language
- Import new scraped data via JSON
- Export flagged listings as CSV or JSON
